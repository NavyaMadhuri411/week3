# Experiment 3: Iterative Prompt Refinement

## Aim
To improve the quality of a language model's response through successive prompt refinement.

## Problem Statement
Explain photosynthesis to a 10-year-old child using three prompt versions: a baseline prompt, a refined prompt with an analogy and simple language, and a final prompt with a mnemonic and diagram description.

## Technologies Used
- Python
- Google Colab
- Google Gemini API
- Google Gen AI SDK

## Algorithm
1. Initialize the Gemini API client securely.
2. Define the baseline prompt.
3. Refine the prompt using a simple analogy and a length constraint.
4. Refine it further by adding a mnemonic and diagram description.
5. Send all three prompts to the same model.
6. Display and compare the responses.
7. Summarize the improvements.

## Expected Output
Three prompt-response pairs and a final comparison describing improvements in clarity, simplicity, and memorability.

## Result
The experiment demonstrates how iterative prompt refinement can make explanations more suitable for the intended audience.
